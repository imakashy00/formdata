How Turnstile works

Optional security, disabled by default.

Frontend

Public site key

Add it to the widget in your website code.

Submission

cf-turnstile-response

The generated token is submitted with the form.

Form settings

Private secret key

Save it in Settings. Never expose it in frontend code.
